## 02 一句话总结

本文提供 Protein Ensemble Database（PED）的详细使用协议，指导用户如何通过网页界面和 API 检索、解读、下载和提交 IDP 构象 ensemble 数据，并以酵母 Sic1 为例演示蛋白页面和实验页面的解读流程。

## 03 研究问题

- **具体问题**：如何高效地探索和使用 PED 中 curated 的 IDP 构象 ensemble 数据？
- **为什么重要**：IDP 构象 ensemble 是理解无序蛋白功能（包括相分离、分子识别等）的核心数据资源。PED 是唯一系统化收集和人工审核这些数据的公共数据库。对于 AI 模型训练（如构象生成、互作位点预测）和物理模拟验证，规范化的数据访问和解读流程至关重要。
- **现有方法为何不足**：PED 于 2014 年首次发布，随着 IDP 领域快速发展，数据量和方法多样性显著增加，旧版数据库的检索功能、元数据描述和验证机制已不能满足需求。2020 年数据库全面更新，但缺乏系统化的使用指南。
- **精确研究问题**：Can a standardized protocol enable researchers to efficiently search, interpret, download, and submit IDP conformational ensembles in PED, thereby supporting reproducible research in IDP biology?

## 04 背景与发展脉络

**脉络标注**：以下脉络基于本文引言和数据库更新描述，属「仅本文框架」，未经外部系统核验。

- **阶段一（2014 年前）**：IDP 构象 ensemble 数据分散在文献中，缺乏统一存储和元数据标准。代表性方法：各实验室自行生成 ensemble（SAXS/FRET/NMR/MD），数据不可比、不可复用。
- **阶段二（2014–2020）**：PED 首次发布，提供基础存储和检索功能。优点：集中存储；局限：元数据不完整、检索功能有限、无系统验证。
- **阶段三（2020 年更新）**：PED 全面重建，引入专职 biocurator 团队，人工审核元数据和方法描述，增加验证报告、API 访问、标准化提交流程。优点：数据质量提升、可编程访问、可追溯性增强；局限：仍依赖作者主动提交，覆盖度有限。
- **本文主张的位置**：作为 2020 版 PED 的官方使用协议，填补了数据库更新后缺乏操作指南的空白，使研究者能充分利用新功能。

## 06 核心思想

**1. 表面方法**：提供一套标准化的 PED 使用协议，包括网页搜索、API 访问、页面解读、数据下载和提交反馈。

**2. 核心洞察**：IDP 构象 ensemble 数据的价值不仅在于数据本身，更在于其元数据（实验条件、方法、验证状态）的完整性和可追溯性。PED 的核心贡献是将「数据存储」升级为「数据治理」，通过人工 curation 确保每个 ensemble 的可解释性和可复用性。

**3. 可能的普适教训 [Analysis]**：对于 IDP/IDR × AI 方向，训练数据的质量直接决定模型上限。PED 的 curation 模式提示：构建 AI 训练集时，不仅需要收集构象坐标，还需系统记录生成条件（温度、pH、实验方法、力场等），并建立验证机制。这一「数据治理」思路可迁移到相分离凝聚体数据、互作组数据等其他 IDP 相关数据资源的建设中。

## 07 方法总览

- **输入**：用户查询（蛋白名称/ID、实验方法、文献等）；或用户提交的 ensemble 数据（坐标文件+元数据）
- **输出**：构象 ensemble 数据（PDB 格式坐标）、元数据描述、验证报告、可视化信息
- **模块**：
  1. 网页搜索界面（Basic Protocol 1）
  2. PED API（Support Protocol 1）
  3. 蛋白页面与实验页面解读（Basic Protocol 2）
  4. 数据下载（Support Protocol 2）
  5. 验证报告解读（Support Protocol 3）
  6. 数据提交（Basic Protocol 3）
  7. 反馈机制（Basic Protocol 4）
- **训练**：不适用（数据库使用指南，非 ML 方法）
- **工具**：网页浏览器、REST API 客户端（如 curl、Python requests）
- **反馈回路**：用户提交数据 → biocurator 审核 → 数据入库 → 用户反馈 → 修正/更新
- **文字流程**：用户通过网页或 API 提交查询 → 系统返回匹配的 ensemble 条目 → 用户进入蛋白页面查看总体信息 → 进入实验页面查看具体 ensemble 的生成方法和条件 → 下载坐标数据 → 解读验证报告确认数据质量 → 如需提交新数据，按模板准备文件并提交 → biocurator 审核后入库

## 14 Agent 提炼的知识候选

**标题：Agent 提炼的知识候选**

1. **数据治理模式**：PED 的「作者提交 + biocurator 审核 + 验证报告」模式可迁移到 IDP 互作数据资源建设。本课题中，若构建 IDP 互作（含相分离）数据集，可借鉴此模式建立元数据标准和验证流程，确保 AI 训练数据的可追溯性。

2. **多实验方法整合**：PED 接受 SAXS、FRET、NMR、MD 及组合方法生成的 ensemble。本课题中，IDP 互作构象可整合多种实验约束（如交联质谱、NMR 化学位移扰动）生成 ensemble，PED 的元数据描述框架可作为记录互作条件（伴侣浓度、盐浓度、温度）的模板。

3. **验证报告机制**：PED 提供 ensemble 与实验数据的吻合度验证。本课题中，AI 生成的 IDP 互作构象或 MD 模拟结果可参照此机制，建立与实验数据的偏差报告，作为模型评估的标准化输出。

4. **API 驱动的数据获取**：PED API 支持程序化访问，本课题中可构建自动化流程，批量获取 IDP ensemble 数据作为 AI 模型（如扩散模型、自回归模型）的训练集，或作为 MD 模拟的初始构象库。

5. **Sic1 用例的启示**：Sic1 是研究较充分的 IDP，其 ensemble 数据可用于验证本课题中 AI 模型对已知 IDP 构象分布的复现能力，作为基准测试案例。

## 15 与已有知识连接

- **DisProt 数据库**：PED 的姊妹数据库，收录 IDP/IDR 注释。两者互补：DisProt 提供序列区域注释，PED 提供构象 ensemble。本课题中可联合使用：DisProt 注释 IDR 区域，PED 获取对应构象。
- **AlphaFold/AlphaFold3**：AF 预测结构通常不适用于 IDP 构象 ensemble（预测单一结构而非 ensemble）。PED 数据可作为评估 AF 在 IDR 区域预测局限性的参考集。
- **MD 力场（如 CHARMM36m、ff14SB）**：PED 中 ensemble 的生成常依赖 MD 模拟，不同力场对 IDP 构象分布的影响可通过 PED 数据比较。
- **相分离数据库（如 LLPSDB、PhaSepDB）**：这些数据库记录相分离蛋白和条件，PED 提供这些蛋白的构象 ensemble，两者结合可研究相分离的构象基础。
- **机器学习构象生成（如 GENESIS、IDPConformerGenerator）**：这些工具生成 IDP ensemble，PED 可作为验证集或训练集。

## 16 研究想法

**标题：Agent 生成的研究候选**

1. **候选名称**：PED-LLPS：整合 PED 构象 ensemble 与相分离条件的 IDP 互作构象数据库
   - **来源局限/观察**：PED 存储单体 IDP ensemble，但缺乏互作（含相分离）状态下的构象数据；相分离数据库（如 LLPSDB）记录条件但不含构象。
   - **核心假设**：IDP 在相分离条件下的构象 ensemble 与单体状态显著不同，且可通过实验条件（盐浓度、温度、伴侣浓度）预测。
   - **相对本文的增量**：扩展 PED 的 curation 模式到互作体系，增加多链 ensemble 和相分离条件元数据。
   - **初步方法**：收集相分离蛋白的 SAXS/FRET/NMR 数据，按 PED 标准格式化，增加互作伴侣和相分离条件字段；开发 API 支持条件筛选。
   - **验证方式**：与 LLPSDB 交叉验证覆盖度；用已知相分离蛋白（FUS、TDP-43）测试数据完整性。
   - **创新状态**：unverified

2. **候选名称**：Ensemble-Former：基于 PED 数据训练的 IDP 构象分布预测模型
   - **来源局限/观察**：现有 AI 结构预测（AF）不输出 ensemble；PED 提供 curated ensemble 但规模有限。
   - **核心假设**：PED 中 ensemble 的构象分布可由序列特征和实验条件预测，且泛化到未收录蛋白。
   - **相对本文的增量**：将 PED 从数据资源转化为训练集，建立序列→构象分布的生成模型。
   - **初步方法**：用 PED 数据训练条件生成模型（如 normalizing flow 或 diffusion model），输入序列+条件（pH、温度），输出 ensemble；用 PED 验证报告作为损失函数。
   - **验证方式**：留一蛋白交叉验证；与 MD 模拟 ensemble 比较构象分布。
   - **创新状态**：unverified

3. **候选名称**：PED-Bench：面向 IDP 互作预测的构象 ensemble 基准测试集
   - **来源局限/观察**：IDP 互作预测（如分子对接、肽结合预测）缺乏标准化的构象 ensemble 基准。
   - **核心假设**：PED 中 ensemble 可作为互作预测的初始构象库，且 ensemble 多样性影响预测精度。
   - **相对本文的增量**：构建标准评测协议，评估不同方法在 IDP 互作预测中的表现。
   - **初步方法**：从 PED 筛选有互作注释的蛋白，生成 ensemble 集合；定义评测指标（结合位点命中率、构象采样效率）；测试现有对接工具。
   - **验证方式**：与实验确定的互作结构比较；评估不同 ensemble 采样策略的影响。
   - **创新状态**：unverified

4. **候选名称**：PED-MD：利用 PED 数据优化 IDP 互作模拟的力场参数
   - **来源局限/观察**：MD 模拟 IDP 互作时，力场参数对构象分布影响大，但缺乏系统校准数据。
