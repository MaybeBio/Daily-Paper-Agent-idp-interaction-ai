## 03 研究问题

- **具体问题**: 机器学习如何在 IDP/IDR 中建立序列→结构偏好→动力学→功能（含互作与相分离）的预测链条？当前方法的边界在哪里？
- **为什么重要**: IDP/IDR 违反经典结构-功能范式，却参与大量关键生物过程（信号转导、相分离、疾病），传统基于折叠蛋白的预测工具（如 AlphaFold 早期版本）对无序区域失效，亟需专门的计算框架。
- **现有方法不足**: 多数 ML 方法以折叠蛋白为训练集，对 IDP 的构象系综、瞬态结构、长程接触预测能力有限；MD 模拟虽能提供系综但计算成本高；实验数据（NMR、SAXS、FRET）稀疏且异质。
- **精确研究问题**: Can machine learning, trained on integrative experimental data and guided by physical principles, accurately predict the conformational ensembles and interaction mechanisms of IDPs/IDRs from sequence alone?

## 06 核心思想

1. **表面方法**: 综述当前 ML 在 IDP 结构预测、动力学模拟加速、互作位点预测、凝聚体形成预测中的应用，并呼吁更多实验-计算整合。
2. **核心洞察**: IDP 的功能不能由单一结构编码，而由「构象系综的统计偏好」编码；ML 的目标不应是预测一个结构，而是预测系综的分布特征（如局部结构倾向、长程接触概率、互作亲和力）。实验数据（NMR 化学位移、SAXS 轮廓、FRET 距离）可作为系综的间接标签，物理模型（力场）可作为正则化器。
3. **可能的普适教训** [Analysis]: 对于「无序×互作×AI」课题，核心教训是：不要试图将无序系统强行映射到有序范式（单一结构预测），而应设计输出为分布/系综的模型，并以多种实验探针作为多视图标签进行联合训练。

## 07 方法总览

本文为综述，无原始方法。但按其框架，可提炼「理想化 ML 工作流」：

- **输入**: 氨基酸序列（+ 实验数据如化学位移、SAXS、FRET 距离，若可用）

- **训练**: 多任务学习，同时最小化结构/动力学预测误差与实验可观测量拟合误差
- **反馈回路**: 预测→实验验证→更新训练集
- **文字流程**: 序列输入 → 编码器提取特征 → 物理约束模块生成候选系综 → 实验对齐模块将系综映射为可观测预测 → 与真实实验数据比较 → 反向传播更新 → 输出系综统计与互作预测

## 14 Agent 提炼的知识候选

**标题: Agent 提炼的知识候选**

1. **系综输出范式**: 对 IDP/IDR 的 ML 预测应输出构象分布而非单一结构。可迁移到本课题：设计预测 SLiM 介导互作或相分离驱动残基的模型时，输出应为「互作概率分布」或「凝聚体形成倾向分数」而非二元分类。
2. **多实验探针联合训练**: 将 NMR 化学位移、SAXS 轮廓、FRET 距离作为多视图标签，联合训练可提升系综预测鲁棒性。可迁移：在预测 IDP 互作界面时，可同时使用交联质谱、突变扫描、结合亲和力数据作为辅助标签。
3. **物理约束作为正则化**: 在 ML 损失函数中加入力场能量项或热力学一致性约束，可减少非物理预测。可迁移：预测相分离驱动序列时，可加入基于 Flory-Huggins 理论或 stickers-and-spacers 模型的物理约束。
4. **SLiM 与相分离的层次建模**: 作者区分了短线性基序介导的互作与凝聚体形成的多价互作，提示本课题应分别建模「局部基序识别」与「全局多价组装」两个层次。
5. **变异解读需动力学视角**: 疾病 SNP 在 IDP 中的效应可能通过改变系综偏好或互作动力学而非结构稳定性实现。可迁移：在预测致病性变异时，特征应包含预测的系综变化（如局部结构倾向改变）而非仅序列保守性。

## 16 Agent 生成的研究候选

**标题: Agent 生成的研究候选**

1. **候选名称**: IDP-SLiM-Interactome 预测器
   - **来源局限/观察**: 作者指出 SLiM 介导的互作是 IDP 功能的核心，但现有 SLiM 预测工具（如 ELM）精度有限，且未考虑序列上下文与动力学。
   - **核心假设**: 结合序列嵌入（如 ESM）与局部结构倾向预测，可显著提升 SLiM 介导互作位点的预测精度。
   - **相对本文增量**: 本文仅讨论 SLiM 的重要性，未提出预测方法；本候选将 ML 具体应用于 SLiM 互作预测。
   - **初步方法**: 使用 ESM-2 嵌入 + 微调 Transformer，以 ELM 数据库和交联质谱数据为标签，输出残基级互作概率。
   - **验证方式**: 在独立测试集上对比 ELM、MoRFpred 等基线，用 AUC/PRC 评估。
   - **创新状态**: partially checked（已有类似工作如 MoRFpred，但结合 ESM 嵌入与动力学特征尚少）
   - **失败模式**: 训练数据稀疏、SLiM 长度短导致信噪比低。

2. **候选名称**: 相分离驱动残基的物理约束 ML 预测器
   - **来源局限/观察**: 作者讨论凝聚体形成是 IDP 的重要功能，但现有预测工具（如 catGRANULES）仅用简单序列特征，未利用物理模型。
   - **核心假设**: 在 ML 损失函数中加入 stickers-and-spacers 模型的能量项，可提升相分离驱动残基的预测精度与可解释性。
   - **相对本文增量**: 本文仅提及凝聚体研究，未提出计算框架；本候选将物理约束引入 ML。
   - **初步方法**: 使用序列特征 + 图神经网络，损失函数 = 交叉熵 + λ × Flory-Huggins 能量偏差。
   - **验证方式**: 在已知相分离蛋白数据集（如 PhaSepDB）上对比 catGRANULES、PSPredictor。
   - **创新状态**: unverified
   - **失败模式**: 物理模型过于简化，无法捕捉拥挤效应或多组分相分离。

3. **候选名称**: IDP 变异效应的系综差异分析框架
   - **来源局限/观察**: 作者指出疾病变异在 IDP 中的效应难以用结构变化解释，需要动力学视角。
   - **核心假设**: 变异通过改变局部结构倾向或长程接触概率来影响功能，而非改变单一结构。
   - **相对本文增量**: 本文仅提出需求，未给出方法；本候选将「系综差异」作为变异效应预测的特征。
