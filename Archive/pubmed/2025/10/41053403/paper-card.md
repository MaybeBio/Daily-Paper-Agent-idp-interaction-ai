## 03 研究问题

- **具体问题**：如何从目标 ensemble 性质（如尺寸、构象偏好、响应性）出发，**反向设计** IDP 的氨基酸序列？
- **为什么重要**：IDP 占真核蛋白组的 30% 以上，参与信号传导、相分离等关键过程，但缺乏稳定折叠使其无法用传统蛋白设计方法（如 Rosetta、AlphaFold）处理。
- **现有方法为何不足**：正向模拟（给定序列预测 ensemble）计算成本高且难以直接用于设计；现有设计方法多针对折叠蛋白，无法处理 IDP 的构象异质性。
- **精确研究问题**：Can we efficiently invert molecular simulations to design IDP sequences that achieve target ensemble properties under arbitrary sequence constraints?

## 06 核心思想

### 1) 表面方法
一个**反向设计框架**：给定目标 ensemble 性质（如 Rg、构象偏好）和序列约束（如长度、氨基酸组成），通过迭代优化序列，使模拟预测的 ensemble 性质逼近目标。

### 2) 核心洞察
IDP 的序列-ensemble 关系虽然复杂，但可以通过**模拟作为可微或可优化的 oracle** 来反转——即不是从序列预测性质，而是从性质反推序列。关键在于设计一个高效的优化循环，使得每次迭代只需少量模拟。

### 3) 可能的普适教训 [Analysis]
对于 IDP/相分离研究，**「目标函数 + 模拟 oracle + 序列约束」** 的三元组设计范式可迁移到其他问题（如设计相分离驱动序列、设计特定互作强度的 binder）。核心是找到可微或可高效采样的模拟代理。

## 07 方法总览

- **输入**：目标 ensemble 性质（如目标 Rg、构象集合）、序列约束（长度、氨基酸组成、特定位置残基）
- **输出**：满足目标性质和约束的 IDP 氨基酸序列
- **模块**：
  1. 序列编码与初始化
  2. 模拟 oracle（coarse-grained 或 atomistic MD）
  3. 性质预测与损失计算
  4. 序列优化器（梯度或非梯度方法）
- **训练**：无监督（无标签数据），基于模拟反馈迭代
- **工具**：未提供具体软件名
- **反馈回路**：序列 → 模拟 → 预测性质 → 与目标比较 → 更新序列
- **假设**：模拟模型能准确反映真实 IDP 的 ensemble 性质；目标性质可被模拟捕捉

**文字流程**：
1. 初始化一个满足基本约束的随机序列
2. 用分子模拟生成该序列的 ensemble
3. 从 ensemble 计算目标性质（如 Rg、接触图）
4. 计算与目标性质的差异（损失）
5. 用优化器更新序列（如遗传算法、梯度估计）
6. 重复 2-5 直到收敛

## 14 学到什么

**Agent 提炼的知识候选**：

1. **模拟反转设计范式**：将「序列→ensemble」的正向模拟反转，通过优化循环从目标性质反推序列。可迁移到 IDP 互作设计：给定目标结合构象偏好，反推 binder 序列。
2. **任意序列约束处理**：框架支持在优化中嵌入约束（如长度、组成、特定残基），这对设计带功能位点的 IDP 互作序列（如保留 PTM 位点）直接有用。
3. **模拟 oracle 的选择**：coarse-grained 模型（如 Mpipi、CALVADOS）可能作为高效 oracle，适合相分离相关序列设计。
4. **「性质→序列」而非「序列→性质」**：对于 IDP 互作，可先定义目标 ensemble 重叠度或结合构象，再反推序列，避免穷举搜索。
5. **与 AI 方法的互补**：AI 方法（如 AlphaFold）不适用于 IDP，本文的模拟驱动方法可作为替代；未来可结合 ML 加速模拟 oracle。
