## 02 一句话总结

本文通过微调四种蛋白语言模型（ProtBERT、ProtT5、ESM2、BiLSTM）在SKEMPI 2.0数据集上预测蛋白对结合亲和力，并利用系统性丙氨酸扫描突变识别界面关键残基，在6063个PDB二聚体上达到N-factor=3时67-68%的界面残基恢复率，在14个人类健康相关复合物上（N-factor=2时37.2%）超过HADDOCK3结构对接（32.1%），证明纯序列方法可替代或辅助结构方法进行结合位点预测。

## 03 研究问题

- **具体问题**: 能否仅从蛋白质序列出发，不依赖三维结构信息，准确预测蛋白质-蛋白质相互作用的结合亲和力并识别界面关键残基（结合位点）？
- **为什么重要**: 
  1. 大多数蛋白质组缺乏实验解析的结构，尤其是IDP/IDR区域
  2. 结构预测（AlphaFold）和对接（HADDOCK）计算成本高、耗时长
  3. 抗体CDR3等高度可变区域的结构预测仍不可靠
  4. 快速筛选大量蛋白对需要可扩展的序列级方法
- **现有方法不足**:
  - 传统机器学习（SVM、随机森林）依赖手工特征工程，难以捕捉深层序列模式
  - 结构对接（HADDOCK3）需要已知或预测的结构，对无序蛋白失效
  - 现有突变预测工具（mCSM-PPI2、SAAMBE等）多依赖结构输入或仅预测单点突变效应，未直接用于结合位点发现
- **精确研究问题**: "Can fine-tuned protein language models, trained solely on sequence data, identify protein-protein interaction interface residues with accuracy comparable to or exceeding structure-based docking methods?"

## 04 背景与发展脉络

**脉络标注**: 仅本文框架（基于本文引言与讨论的梳理，未做外部文献核验）

- **阶段一：传统机器学习方法（SVM、随机森林）**
  - 代表方法：基于氨基酸组成、二肽组成、conjoint triad、Doc2Vec、PSSM等特征
  - 优点：可解释性较好、计算轻量
  - 局限：特征工程繁琐，难以捕捉非线性关系和深层序列模式

- **阶段二：结构预测与对接方法**
  - 代表方法：AlphaFold2/AlphaFold-Multimer、HADDOCK3
  - 优点：提供三维空间信息，物理化学约束明确
  - 局限：推理时间长；对无序蛋白/IDR预测不可靠；对接结果受结构质量影响大

- **阶段三：蛋白语言模型（PLM）迁移学习**
  - 代表方法：ProtBERT、ProtT5、ESM2（自监督预训练于大规模蛋白序列语料）
  - 优点：隐式编码序列-结构-功能关系；无需显式结构输入；推理速度快
  - 局限：对细微突变（单点）的敏感性不足；缺乏显式几何约束

- **本文主张的位置**: 首次将PLM微调用于「结合亲和力预测 + 丙氨酸扫描突变 → 结合位点识别」的端到端流程，并系统评估其在大型二聚体数据集上的表现，证明序列方法可达到甚至超过结构对接的界面残基恢复率。

## 06 核心思想

**1) 表面方法**:
- 微调四种序列编码器（ProtBERT、ProtT5、ESM2、BiLSTM）于SKEMPI 2.0突变数据
- 采用Siamese网络架构处理蛋白对，输出结合亲和力（ΔG）
- 对每个残基逐一进行丙氨酸替换，通过预测ΔG变化识别关键残基
- 提供Web服务器和Google Colab实现

**2) 核心洞察**:
- 蛋白语言模型的embedding隐式编码了残基在互作中的功能重要性——即使没有显式结构输入，PLM的上下文感知表示足以捕捉残基对结合的贡献
- 丙氨酸扫描作为一种「可微」的探针：通过系统扰动每个残基并观察预测ΔG变化，将黑盒回归模型转化为可解释的残基重要性图谱
- 序列方法的优势在于「零结构依赖」——对IDP/IDR、膜蛋白等结构难解析体系天然适用
- 多残基连续突变（patch）比单点突变产生更强的可检测信号，说明PLM对局部序列上下文的扰动更敏感

**3) 可能的普适教训** [Analysis]:
- 对于IDP/IDR介导的互作，序列embedding可能比结构预测更可靠——因为IDP的构象ensemble无法用单一结构表示，而PLM的隐式统计可能编码了ensemble层面的互作倾向
- 「扰动-响应」范式（perturbation-response paradigm）可推广到其他功能预测任务：不仅预测静态属性，而是通过系统扰动揭示残基层面的功能贡献
- 序列方法可作为结构方法的「prior」：在对接或MD模拟前，先用序列方法缩小候选残基范围，降低计算维度

## 07 方法总览

**输入**: 蛋白质对序列（两条链的氨基酸序列）

**输出**: 
1. 结合亲和力预测值（ΔG，kcal/mol）
2. 每个残基的丙氨酸扫描ΔΔG值 → 结合位点残基排名

**模块**:
1. **序列编码器**: ProtBERT / ProtT5 / ESM2 / BiLSTM（四种可选）
2. **Siamese网络**: 双塔结构，分别编码两条链，融合后接回归头
3. **回归头**: 多层线性层 + ReLU + Dropout，输出标量ΔG
4. **丙氨酸扫描引擎**: 对每个残基逐一替换为丙氨酸，重新预测ΔG，计算ΔΔG

**训练**:
- 数据: SKEMPI 2.0（5387对，70%训练/30%验证）
- 损失函数: MSE、MAE、Huber（均测试）
- 评估指标: MAE（亲和力预测）；N-factor恢复率（结合位点识别）

**推理流程**:
1. 输入蛋白对序列 → 编码器生成embedding
2. Siamese融合 → 预测野生型ΔG
3. 对链A每个残基i：替换为A → 预测突变体ΔG_i → ΔΔG_i = ΔG_mut - ΔG_wt
4. 对链B重复
5. 按|ΔΔG|降序排列残基，取前N×n个作为预测结合位点（n为真实界面残基数）

**计算效率**: A100 GPU上约46 seq/s（ProtBERT）、10.9 seq/s（ESM2）、4.96 seq/s（ProtT5）

## 09 关键公式符号

**1. 结合亲和力-解离常数关系**（Methods节）:
```
ΔG = RT · ln(KD)
```
- ΔG: 结合自由能（kcal/mol）
- R: 气体常数
- T: 温度（K）
- KD: 解离常数

**2. 丙氨酸扫描ΔΔG计算**（Methods节，隐含）:
```
ΔΔG_i = ΔG_mut(i→A) - ΔG_wt
```
- ΔΔG_i: 第i个残基突变为丙氨酸后的结合自由能变化
- ΔG_mut(i→A): 突变体预测结合自由能
- ΔG_wt: 野生型预测结合自由能

**3. N-factor评估指标**（Methods节）:
```
k = N × n
```
- k: 考虑的top预测残基数
- n: 真实界面残基数
- N: 因子（1, 2, 3）

**4. 恢复率（Success Rate）**（Results节）:
```
Recovery = (预测的top k残基中 ∩ 真实界面残基) / n
```

## 11 结论正确解读

- **任务范围**: 本文解决的是「给定蛋白对序列，预测哪些残基位于结合界面」的二分类/排序问题，而非「预测结合构象」或「预测结合亲和力绝对值」。
- **Oracle/真值输入**: 训练数据来自SKEMPI 2.0实验突变数据；评估真值为PDB结构中基于距离（6.5 Å）定义的界面残基。这意味着「界面残基」的定义依赖于结构注释，对IDP体系可能不适用。
- **端到端状态**: 方法完全端到端——从序列到ΔG预测再到残基重要性排序，无需中间结构预测步骤。
- **算力成本**: 推理速度快（秒级到分钟级），远低于结构预测+对接流程（小时级）。
- **历史数据依赖**: 训练数据SKEMPI 2.0偏向于已充分研究的蛋白复合物，可能存在类别偏差。
- **模型依赖**: 性能高度依赖预训练PLM的质量；不同PLM（ESM2 vs ProtBERT vs ProtT5）表现有差异。
- **最难情形**: 氢键介导的界面残基（恢复率仅11.5-19.5%）；单点突变场景；某些特定复合物（如6UZK、7WBP）恢复率极低。
- **群体/领域边界**: 训练和评估数据均为有序蛋白复合物（PDB可解析结构）；对IDP/IDR介导的互作，由于缺乏结构真值，本文方法无法直接评估，但序列输入的特性使其具有潜在适用性。
- **不确定性**: 预测ΔΔG的绝对值范围因模型而异（LSTM和T5范围极窄，-0.795到0.822 kJ/mol），说明不同模型对突变效应的敏感度差异大，ΔΔG的绝对数值不可跨模型比较。

**有边界的复述**: 在PDB可解析结构的有序蛋白复合物上，微调PLM通过丙氨酸扫描预测的界面残基，在允许N=2-3的候选范围时，恢复率超过HADDOCK3结构对接；但在N=1的严格条件下，与最优突变预测工具（SAAMBE-3D）相当或略低。该方法不依赖结构输入，推理速度快，适合作为大规模蛋白互作筛选的初筛工具。

## 14 Agent 提炼的知识候选

**面向课题方向（IDP/IDR × 蛋白互作 × AI/物理模拟）的可迁移知识**:

1. **「扰动-响应」范式用于残基重要性映射**:
   - 核心思想：通过对每个残基进行系统扰动（丙氨酸替换），观察模型预测变化，将黑盒回归转化为可解释的残基重要性图谱
   - 迁移到IDP课题：对IDP/IDR序列进行系统扰动（如磷酸化模拟突变S→E、IDP倾向性残基替换），观察相分离行为或互作亲和力的预测变化，可识别驱动相分离的关键残基
   - 实现方式：在现有相分离预测器（如catGRANULE、PSPredictor）上应用同样的扰动-响应分析

2. **PLM隐式编码互作信息**:
   - 核心发现：PLM的embedding即使未经结构训练，也隐式编码了残基在互作中的功能重要性
   - 迁移到IDP课题：IDP的互作倾向可能同样被PLM隐式编码——可利用PLM的注意力权重或embedding相似性来预测IDP的互作区域（MoRF, Molecular Recognition Feature），无需显式结构
   - 具体操作：提取ESM2/ProtT5对IDP序列的embedding，训练轻量分类器区分MoRF/非MoRF区域

3. **序列方法作为结构方法的prior**:
   - 核心思想：序列预测可作为对接/MD的候选区域筛选器，降低计算维度
   - 迁移到IDP课题：对IDP-蛋白互作，先用Seq2Bind类方法预测候选互作残基，再仅对这些区域进行MD模拟或对接采样，避免对全长IDP进行昂贵采样
   - 特别适用于相分离体系：预测驱动相分离的「sticker」区域，指导后续凝聚体模拟

4. **N-factor评估协议**:
   - 核心思想：通过N×n的top-k评估，平衡灵敏度与特异度，适应不同下游需求
   - 迁移到IDP课题：在评估IDP互作位点预测器时，采用类似的多阈值评估协议，而非单一指标

5. **Siamese架构处理蛋白对**:
   - 核心思想：双塔共享权重编码两条链，融合后预测互作属性
   - 迁移到IDP课题：可用于预测IDP-蛋白对、IDP-IDP对的互作亲和力或相分离倾向，输入为两条序列，输出为共定位/凝聚倾向分数

6. **零结构依赖的互作预测**:
   - 核心发现：即使完全无结构信息，序列模型也能达到与结构对接相当的界面恢复率
   - 迁移到IDP课题：对无法获得结构的IDP体系，序列方法可能是唯一可行的互作位点预测途径；可结合AlphaFold对IDP区域的低置信度预测，设计混合策略

## 15 与已有知识连接

- **SKEMPI 2.0数据库**（Jankauskaitė et al., 2019, Bioinformatics）: 本文训练与评估的基础数据，包含实验测定的突变结合自由能变化。该数据库主要覆盖有序蛋白复合物，对IDP体系覆盖有限——这是迁移到IDP课题时需注意的数据偏差。

- **蛋白语言模型**:
  - ProtBERT/ProtT5（Elnaggar et al., 2022, IEEE TPAMI）: 基于BERT/T5架构的蛋白序列模型
  - ESM2（Lin et al., 2023, Science）: 650M参数进化尺度模型，本文使用esm2_t33_650M_UR50D变体
  - 这些模型在IDP预测中已有应用（如IDP倾向性预测、MoRF预测），本文将其扩展到互作位点预测

- **HADDOCK3**（van Zundert et al., 2016, J Mol Biol）: 信息驱动对接软件，本文作为结构基线。对IDP体系，HADDOCK3通常需要额外处理（如半柔性对接、ensemble对接），本文的比较结果提示序列方法在IDP场景可能更具优势 [Analysis]。

- **突变预测工具**:
  - mCSM-PPI2（Rodrigues et al., 2019, Bioinformatics）: 基于图签名
  - SAAMBE-3D/SAAMBE-SEQ（Pahari et al., 2020, J Mol Biol）: 基于3D/序列特征
  - 这些工具多依赖结构或手工特征，本文的PLM方法代表范式转变

- **IDP/相分离预测的连接** [Analysis]:
  - 本文方法预测的是「结合位点」，而IDP/相分离领域关注「互作热点」和「sticker/spacer」模式
  - 本文的丙氨酸扫描ΔΔG排序可类比于相分离领域的「sticker」识别——两者都试图通过扰动识别驱动互作的关键残基
  - 可探索将本文方法应用于已知相分离驱动蛋白（如FUS、TDP-43、hnRNPA1）的IDR区域，验证预测热点是否与实验验证的相分离驱动残基一致

- **候选方向** [Analysis]:
  - 与AlphaFold3/AlphaFold-Multimer的互补：AFM对IDP复合物预测置信度低，本文序列方法可作为替代或补充
  - 与MD模拟结合：预测热点可作为MD模拟的初始接触点或增强采样目标区域
  - 与相分离粗粒化模型结合：预测的互作热点可映射到Pi-Pi接触、电荷互补等相互作用类型，指导粗粒化模型参数化

## 16 Agent 生成的研究候选

**候选1: IDP-MoRF-Former——基于PLM微调的IDP分子识别特征（MoRF）预测器**
- **来源局限/观察**: 本文方法在有序蛋白上有效，但IDP的互作位点（MoRF）通常位于长无序区域内，且缺乏结构真值；本文的6.5 Å界面定义不适用于IDP
- **核心假设**: PLM的embedding可编码IDR内的MoRF区域，即使这些区域无稳定结构
- **增量**: 将本文的Siamese+丙氨酸扫描框架迁移到IDP-蛋白互作体系，使用实验验证的MoRF数据库（如MoRFpred数据库）作为真值
- **初步方法**: 在IDP-蛋白对数据集上微调ESM2，输出每个残基的MoRF概率；采用本文的N-factor评估协议
- **验证方式**: 与现有MoRF预测器（如MoRFpred、ANCHOR2）对比；在相分离相关蛋白（FUS、TDP-43）上验证
- **创新状态**: unverified

**候选2: Seq2Phase——基于丙氨酸扫描的相分离驱动残基（stickers）预测**
- **来源局限/观察**: 本文的丙氨酸扫描ΔΔG排序本质上是「哪些残基对互作贡献最大」的排序，这与相分离领域的「sticker」概念高度一致
- **核心假设**: 在IDR序列上应用本文的丙氨酸扫描框架，预测的ΔΔG热点可识别驱动相分离的关键残基
- **增量**: 将互作位点预测扩展到相分离行为预测；建立「序列→ΔΔG热点→相分离倾向」的端到端流程
- **初步方法**: 在已知相分离蛋白IDR上运行Seq2Bind丙氨酸扫描，将预测热点与实验验证的相分离驱动残基（如FUS的酪氨酸残基）对比；结合catGRANULE等序列特征
- **验证方式**: 与实验相分离数据（如LLPS数据库）对比；预测的sticker区域是否富集π-π、阳离子-π等已知相分离驱动相互作用
- **创新状态**: unverified

**候选3: Seq2Dock-Prior——序列预测作为IDP-蛋白对接的约束prior**
- **来源局限/观察**: 本文方法在N=2-3时超过HADDOCK3盲对接，但对IDP体系，对接本身因构象多样性而失效
- **核心假设**: 序列预测的候选互作残基可作为IDP-蛋白对接的约束，显著缩小构象搜索空间
- **增量**: 将序列预测与结构方法结合，而非替代；特别针对IDP-蛋白体系
- **初步方法**: 用Seq2Bind预测IDP-蛋白对的候选互作残基，将这些残基作为HADDOCK3或MD模拟的接触约束（distance restraints），比较有无约束的对接成功率
- **验证方式**: 在已知IDP-蛋白复合物（如p53-MDM2、PUMA-Bcl-xL）上测试；比较约束对接vs盲对接的native contact恢复率
- **创新状态**: unverified

**候选4: 多模态PLM——整合序列与AlphaFold置信度图的IDP互作预测**
- **来源局限/观察**: 本文纯序列方法在有序蛋白上有效，但IDP区域在AlphaFold中通常表现为低置信度（pLDDT < 50），这本身可能是IDP互作位点的信号
- **核心假设**: AlphaFold的pLDDT和PAE图可提供IDP区域互作倾向的补充信号，与PLM序列embedding互补
- **增量**: 多模态输入（序列+结构预测置信度），而非纯序列或纯结构
- **初步方法**: 将ESM2 embedding与AlphaFold pLDDT/PAE特征拼接，训练IDP互作位点预测器；在IDP-蛋白数据集上评估
- **验证方式**: 与纯序列方法（本文方法）和纯结构方法对比；在相分离蛋白上验证
- **创新状态**: unverified

**候选5: 跨物种IDP互作泛化性评估**
- **来源局限/观察**: 本文训练数据（SKEMPI 2.0）和评估数据（PDB二聚体）均偏向模式生物和人类蛋白，对病毒IDP、植物IDP等覆盖不足
