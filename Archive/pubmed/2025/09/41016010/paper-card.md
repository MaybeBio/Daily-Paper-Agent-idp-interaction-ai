## 02 一句话总结

本文通过构建 121 个 ELM 基准互作对（其中 26 对无 PDB 同源性），系统评估了 AlphaFold2/3 多种指标（MiniPAE、MinD、AlphaSLiM 等）在 SLiM-结构域互作二分类和基序定位中的表现，发现非平衡筛选场景下精度急剧下降，据此提出基于幂律拟合的自适应 MiniPAE 阈值策略，并结合 BioID2 邻近标记实验验证了 13 个新的 RSK2 结合 SLiM。

## 03 研究问题

- **具体问题**: AlphaFold（AF2/AF3）能否在真实筛选场景下（非平衡、无 PDB 同源先验）可靠地识别 SLiM 介导的蛋白互作？如何设定合理的置信阈值？
- **为什么重要**: SLiM 是嵌入在无序区中的短小互作模块，调控大量细胞信号通路，但实验检测困难。若 AlphaFold 能可靠预测 SLiM-结构域互作，将极大加速互作组学发现。然而，真实筛选场景中非结合子远多于结合子，模型的特异性（而非灵敏度）决定了实用性。
- **现有方法不足**: 以往基准多基于 PDB 中已有结构同源性的复合物，存在训练集偏差；且多采用平衡数据集评估，无法反映真实筛选场景；此外，缺乏对 AF3 的系统评估。
- **精确研究问题 (Can...?)**: Can AlphaFold2/3, when applied to a large unbalanced set of candidate protein pairs (mimicking real-world screening), reliably discriminate true SLiM-mediated interactions from non-binders, and can an adaptive threshold based on the number of candidates maintain acceptable precision?

## 04 背景与发展脉络

*注：以下脉络基于本文框架及引用文献，标记为「经外部核验」的部分来自文中引用的公开文献。*

1. **SLiM 计算预测早期阶段（序列基序方法）**：MEME、STREME 等序列基序发现工具。优点：快速、可大规模扫描。局限：SLiM 短小且简并，序列信号弱，假阳性率高；不提供结构信息，不预测结合伴侣。[经外部核验：文中 Discussion 引用]
2. **基于无序预测和深度学习的 SLiM 区域预测**：AIUPred-binding、MoRFchibi 2.0 等。优点：速度快、能从序列中识别可能的互作无序区域。局限：不预测具体结合伴侣，不提供结构模型。[经外部核验：文中 Discussion 引用]
3. **AlphaFold 用于 SLiM-结构域互作预测（当前阶段）**：早期研究（如 Bret et al. 2024）发现 AF2 能建模部分 IDR-结构域互作；Lee et al. 系统比较了 AF 指标；Omidi et al. 引入 MinD 和 MiniPAE 指标。优点：提供结构假设和伴侣信息。局限：特异性不足，非平衡场景下精度下降，缺乏系统工作流和阈值指导。[经外部核验：文中 Introduction/Results 引用]
4. **本文位置**：在上述基础上，(a) 引入结构无关基准（noPDB_dataset）；(b) 首次系统对比 AF2 与 AF3；(c) 量化非平衡场景下的性能衰减并给出自适应阈值公式；(d) 提供完整可复现的 Colab 工作流 + 实验验证闭环。

## 07 方法总览

- **输入**: 目标蛋白（POI）氨基酸序列 + 候选互作蛋白列表（来自 BioGRID/IntAct 等数据库或内部数据）
- **输出**: 候选 SLiM 序列、坐标、MiniPAE 分数、排序列表及推荐阈值
- **模块**:
  1. 候选蛋白选择（数据库筛选）
  2. 二元复合物结构预测（AF2 via ColabFold multimer V3 默认参数；AF3 via AF Server）
  3. 指标计算（MiniPAE、MinD、AlphaSLiM、MC、pLDDT 等）
  4. 自适应阈值设定（幂律拟合）
  5. 实验验证（BioID2 邻近标记）
- **训练**: 无（AF 为预训练模型，本文不进行微调）
- **工具**: ColabFold、AF Server、Python（curve_fit、scikit-learn）、PDBePISA、Prism
- **反馈回路**: 实验验证结果可反馈优化阈值和候选列表
- **文字流程**: 从数据库获取候选互作蛋白 → 使用 ColabFold 对每个候选与 POI 进行二元复合物结构预测 → 从输出 PAE 矩阵计算 MiniPAE 分数 → 根据候选数量 n 用幂律公式计算自适应阈值 → 筛选低于阈值的候选作为高置信 SLiM 互作 → 对候选 SLiM 进行实验验证（BioID2 邻近标记）→ 验证后的 SLiM 可进一步用于基序比对和数据库搜索

## 09 关键公式符号

1. **MC 分数**（模型置信度）:
   \[
   MC = 0.2 \cdot pTM + 0.8 \cdot ipTM
   \]
   - pTM: 预测模板建模分数（predicted template modeling score），衡量整体拓扑置信度
   - ipTM: 界面 pTM（interface pTM），衡量亚基间相对位置置信度
   - 来源：Methods 节

2. **自适应阈值**（幂律模型）:
   \[
   T(n) = a \cdot n^b + c
   \]
   - n: 预测分析的候选数量
   - a, b, c: 拟合参数（通过 scipy curve_fit 从非结合子数据拟合）
   - 用途：当筛选规模增大时，阈值自动收紧以控制假阳性
   - 来源：Results 图 2F、Methods 节

3. **归一化分数**（用于比较不同指标）:
   \[
   Score_{norm} = \frac{Score}{Score_{max}}
   \]
   - 用于 MiniPAE、MinD、AlphaSLiM、BSA 等指标的可视化比较
   - 来源：Methods 节

## 10 实验设计与证据链

**数据集与规模**:
- ELM_dataset: 121 个互作对（来自 ELM 数据库，人类-人类互作，每个对应不同 ELM_Class）
- noPDB_dataset: 上述 121 对中 26 对无 PDB 同源性的子集
- nonBinder_dataset: 1100 个随机打乱配对的非结合子（从 ELM_dataset 生成）
- RSK2 筛选: 220 个候选蛋白（来自 BioGRID/IntAct/PhosphoSitePlus）

**指标**: ROC AUC、PR-AUC、召回率（recall at FDR=0%）

**评测协议**: 
- 二分类任务：结合子 vs 非结合子，使用多种 AF 衍生指标
- 定位任务：在已知 SLiM 区域内的残基级分数比较
- 非平衡模拟：1:1、1:5、1:25 结合子与非结合子比例

## 11 结论正确解读

- **任务范围**: 本文评估的是 SLiM-结构域二元复合物的结构预测，而非所有 IDR 介导的互作。结论不适用于：IDR-IDR 互作、相分离驱动的多价互作、翻译后修饰依赖的互作。
- **oracle/真值输入**: 基准数据来自 ELM 数据库（实验验证的 SLiM 注释），但 ELM 注释本身存在偏差（偏向已知基序类别）。
- **端到端状态**: 工作流是「半自动」的——候选蛋白选择需要数据库或人工输入，最终验证需要实验。计算部分仅提供候选排序。
- **算力成本**: 220 个候选蛋白的 AF2 预测需要大量 GPU 时间（文中未给出具体数值），且预测时间随序列长度指数增长。
- **历史数据依赖**: AF2/AF3 训练数据包含 PDB 中的复合物结构，尽管 noPDB_dataset 排除了同源性，但训练数据中可能包含类似折叠模式的隐式信息。
- **模型依赖**: 结论基于 ColabFold multimer V3 和 AF Server 的特定版本，未来版本可能改变性能。
- **最难情形**: 非平衡筛选（1:25 以上）、低亲和力瞬时互作、非经典基序（如不匹配已知 ELM 类别的基序）。
- **群体/领域边界**: 结果基于人类蛋白；其他物种的 SLiM 组学特征可能不同。
- **不确定性**: 实验验证仅覆盖 RSK2 一个案例，且 8 个测试样本中 1 个未通过验证，说明存在假阳性风险。

**有边界的复述**: 在人类蛋白范围内，当候选蛋白列表来自互作数据库（已富集真结合子）时，AF2 + MiniPAE 自适应阈值工作流可以中等精度（~70% AUC）排序 SLiM 介导的互作候选，并通过实验验证达到约 88% 的验证率（7/8）；但该方法不适用于全蛋白质组盲筛，且对非平衡数据的特异性有限。

## 14 学到什么

**Agent 提炼的知识候选**：

1. **MiniPAE 作为 SLiM 筛选的首选指标**：在多种 AF 衍生指标中，MiniPAE 在定位任务中表现最优且实现最简单（仅需 PAE 矩阵）。可迁移到本课题：对于 IDR 介导的互作预测，优先计算 MiniPAE 而非复杂自定义指标。

2. **非平衡评估的必要性**：平衡数据集下的 AUC 会严重高估实际筛选性能。本课题（无序蛋白互作预测）同样面临真实筛选场景中负样本远多于正样本的问题，应使用 PR-AUC 和非平衡模拟评估。

3. **自适应阈值的幂律拟合策略**：阈值随候选数量 n 按幂律缩放，这一思路可推广到任何基于结构预测的大规模筛选场景。本课题可借鉴：当筛选规模从几十扩展到几千时，固定阈值必然失效。

4. **结构无关基准的设计**：通过排除 PDB 同源性来评估模型真实泛化能力，是避免「记忆效应」的关键。本课题可借鉴：构建 IDR 互作基准时，应明确排除训练集同源结构。

5. **计算预测 + 邻近标记实验的闭环**：BioID2 邻近标记适合验证低亲和力 SLiM 互作，这一实验范式可迁移到本课题的 IDR 互作验证中，特别是当传统 pull-down 无法捕获瞬时互作时。

6. **候选蛋白预筛选策略**：从互作数据库（BioGRID/IntAct）而非全蛋白质组开始，显著提高先验概率。本课题可借鉴：结合互作组学数据 + 无序区注释（如 IUPred、AIUPred-binding）进行候选预筛选。

7. **AF2 优于 AF3 的实用建议**：尽管 AF3 架构更新，但在 SLiM 预测任务中 AF2 仍具优势。本课题可借鉴：不要盲目追新模型，需针对具体任务进行基准测试。

8. **多指标互补性有限**：组合多种指标（AlphaSLiM、MinD、MiniPAE）并未显著提升性能。本课题可借鉴：优先优化单一有效指标，而非堆叠指标。

## 16 研究想法

**Agent 生成的研究候选**：

1. **候选名称**: SLiM-相分离互作组整合预测
   - **来源局限/观察**: 本文工作流仅针对二元 SLiM-结构域互作，未覆盖相分离中常见的多价 IDR-IDR 互作；且候选预筛选依赖互作数据库，可能遗漏相分离相关的新型互作。
   - **核心假设**: 将 AF 预测（MiniPAE）与序列特征（如电荷模式、疏水块、芳香族残基含量）结合，可预测相分离驱动的 IDR-IDR 互作。
   - **初步方法**: 构建 IDR-IDR 互作基准（从 LLPS 数据库如 PhaSepDB 提取）；对每个 IDR 对运行 AF2 预测并计算 MiniPAE；结合序列特征训练分类器；用体外相分离实验验证。
   - **验证方式**: 与已知相分离互作对比召回率；新预测互作的体外验证。
   - **可能的失败模式**: AF 对 IDR-IDR 互作预测置信度普遍较低；相分离互作可能不依赖单一高置信界面。

2. **候选名称**: 无序区互作预测的负样本生成策略
   - **来源局限/观察**: 本文负样本通过随机打乱生成，可能过于「容易」；真实场景中负样本可能具有部分结合倾向。
   - **核心假设**: 基于「近缘非结合子」（如来自同一蛋白家族但不结合的同源物）的负样本能更准确评估模型真实特异性。
   - **初步方法**: 从 ELM 数据库构建「同源非结合子」负样本集；对比随机负样本与同源负样本下的模型性能差异；开发针对同源负样本的校准策略。
   - **验证方式**: 在多个独立数据集上比较不同负样本生成策略下的 PR-AUC。
   - **可能的失败模式**: 同源非结合子难以大规模构建；模型在同源负样本下性能过低，无法使用。

3. **候选名称**: 基于 MiniPAE 的 IDR 结合位点精细定位
   - **来源局限/观察**: 本文 MiniPAE 仅用于二分类和粗定位，未充分利用 PAE 矩阵中的残基级信息。
   - **核心假设**: PAE 矩阵中的局部最小值簇可精确映射 SLiM 核心残基，且与实验验证的基序一致。
   - **初步方法**: 对 ELM_dataset 中每个互作对提取 PAE 矩阵，识别跨蛋白最低 PAE 残基簇；与已知 SLiM 注释比对；开发可视化工具。
   - **验证方式**: 与 ELM 注释的基序边界比对；突变实验验证关键残基。
   - **可能的失败模式**: PAE 分辨率不足以精确定位 3-10 个残基的基序；不同 AF 运行间 PAE 波动大。

4. **候选名称**: 无序区长度与 AF 预测置信度的关系建模
   - **来源局限/观察**: 本文未分析 IDR 长度对预测性能的影响；已知 AF 对长无序区建模可靠性下降。
   - **核心假设**: IDR 长度、无序程度（预测分数）与 MiniPAE 判别力存在可量化的非线性关系。
   - **初步方法**: 将 ELM_dataset 按 IDR 长度分层；分析各层 AUC 变化；拟合长度-性能衰减模型；开发长度校正的阈值函数。
   - **验证方式**: 在独立数据集上验证长度校正阈值的泛化性。
   - **可能的失败模式**: 样本量不足以支持分层分析；长度与性能关系可能被其他因素混淆。

5. **候选名称**: 多聚体 SLiM 互作的 AF 预测扩展
   - **来源局限/观察**: 本文仅处理二元复合物；真实 SLiM 互作常涉及多聚体组装（如脚手架蛋白同时结合多个配体）。
   - **核心假设**: 通过逐步二元预测 + 几何约束组装，可预测多价 SLiM 互作界面。
   - **初步方法**: 选择已知三聚体 SLiM 复合物；分别预测每个二元对；用几何匹配算法组装；与实验结构对比。
   - **验证方式**: 与 Cryo-EM/XL-MS 结构对比；突变破坏多聚化的实验验证。
   - **可能的失败模式**: AF 对多聚体预测的累积误差；几何组装算法不收敛。
