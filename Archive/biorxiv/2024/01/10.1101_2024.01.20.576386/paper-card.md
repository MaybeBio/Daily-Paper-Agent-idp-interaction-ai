## 02 一句话总结

本文提出 AFM-RL，先用 AlphaFold-Multimer 对复合物中所有链对生成多样化的成对对接模型（通过冗余链拷贝强制采样），再用强化学习（Q-learning + UCB + ε-greedy）逐步组装这些成对模型为完整复合物，在 57 个 6-20 链复合物上平均 RMSD 10.09 Å、TM-score 0.81，优于 MoLPC（RMSD 18.63 Å）。

## 03 研究问题

- **具体问题**：如何预测包含 6-20 条链的大型蛋白复合物的三维结构？
- **为什么重要**：大型复合物在细胞中执行关键功能，但实验测定困难；计算预测可补充实验，且大规模预测有助于理解复合物组装原理。
- **现有方法不足**：
  - AlphaFold-Multimer 直接端到端预测大复合物时，GPU 内存不足（40GB 下 15/57 个目标 OOM），且精度随链数增加而下降。
  - 传统多链对接方法（如 MoLPC）受限于组合爆炸，且依赖子结构预测质量。
  - 现有方法在链数 >6 时缺乏系统性评测。
- **精确研究问题**：Can a decomposition-and-assembly strategy, combining AlphaFold-Multimer for pairwise docking with reinforcement learning for assembly, accurately predict the quaternary structure of protein complexes with 6-20 chains?

## 06 核心思想

### 1) 表面方法
- 用 AFM 对所有链对生成成对模型（pairwise decoys），其中对每个链对输入冗余拷贝（如 A1B3）以强制 AFM 输出多种界面构象。
- 用 Q-learning 强化学习框架，将组装过程建模为马尔可夫决策过程：状态 = 已组装亚基集合，动作 = 选择下一个亚基及其成对模型。
- 组装完成后用打分函数（分子力学势 + 溶剂可及表面积 + 回旋半径 + 原子冲突数）评估，奖励反馈更新 Q 表。

### 2) 核心洞察
- **强制采样（forced sampling）**：通过向 AFM 输入冗余链拷贝，迫使模型输出同一链对的多种界面构象，从而保留关键互作界面，避免分解时丢失重要接触。
- **RL 作为搜索策略**：将组装视为序贯决策问题，用 UCB 平衡探索/利用，用 ε-greedy 保证随机性，避免贪心组装陷入局部最优。
- **动态目标**：奖励基于当前最佳模型而非固定目标，使搜索过程持续向更优构象收敛。

### 3) 可能的普适教训 [Analysis]
- 对深度学习预测器，**输入扰动（如冗余拷贝）可有效扩增输出多样性**，这一思路可迁移至 IDR 构象采样：对同一序列多次采样或引入扰动，可生成更多样的构象集合。
- **分解-组装框架**天然适合模块化复合物，对 IDR 介导的弱互作，可先预测局部互作模块再组装，避免全局预测的困难。

## 07 方法总览

- **输入**：复合物所有链的氨基酸序列（FASTA 格式）。
- **输出**：完整复合物的三维结构模型（PDB 格式），以及打分排序后的模型列表。
- **模块**：
  1. **Pairwise docking 模块**：对每对链运行 AFM，输入冗余拷贝（A1B3）强制多样化，输出 75 个候选成对模型/链对。
  2. **RL 组装模块**：Q-learning 框架，状态 = 已组装亚基集合，动作 = 选择下一个亚基及对应成对模型。
  3. **打分模块**：线性组合 4 项打分（分子力学势、溶剂可及表面积、回旋半径、原子冲突数），权重由逻辑回归 + 4 折交叉验证确定。
  4. **聚类模块**：LB3DClust 对生成模型聚类，VoroMQ 打分排序。
- **训练**：打分函数权重在训练集上通过逻辑回归学习；RL 参数（学习率、折扣因子、ε、UCB 常数 C）通过少量目标手工调参。
- **反馈回路**：组装模型打分 → 奖励 → Q 表更新 → 影响后续动作选择。
- **文字流程**：
  1. 输入序列 → 2. 对每对链运行 AFM（含冗余拷贝）→ 3. 提取所有成对模型 → 4. RL 从空状态开始，逐步选择亚基和成对模型组装 → 5. 完整模型打分 → 6. 奖励更新 Q 表 → 7. 重复多轮（episodes）→ 8. 聚类 + 排序输出最终模型。

## 09 关键公式符号

### 1) UCB 策略（选择下一个组装状态）

\[
\text{score}_i = v_i + C \sqrt{\frac{\ln N}{n_i}}
\]

- \( v_i \)：组装状态 i 的值（Q 值）
- \( C \)：探索常数，初始 1.0，随 episode 递减
- \( N \)：父状态总访问次数
- \( n_i \)：状态 i 的访问次数

**用途**：在探索（访问少的状态）与利用（高值状态）间平衡。

### 2) Metropolis 接受准则（部分奖励）

\[
P = \exp\left(-\frac{\Delta E}{k_b T}\right)
\]

- \( \Delta E \)：新模型分数与当前最佳分数之差
- \( k_b T \)：归一化因子，设为 6.0

**用途**：决定是否接受分数低于当前最佳的模型，并据此分配部分奖励。

### 3) 状态值更新

\[
v_i \leftarrow v_i + \eta \cdot r_t
\]

- \( \eta \)：学习率，设为 1.0
- \( r_t \)：episode 结束时的奖励（100 分最佳，10 分可接受，-2 分冲突拒绝）

**用途**：更新组装状态的值。

### 4) Q 表更新（Bellman 方程）

\[
Q(s,a) \leftarrow Q(s,a) + \alpha \left[ R(s,a) + \gamma \max_{a'} Q(s',a') - Q(s,a) \right]
\]

- \( \alpha \)：自适应学习率，从 1.0 衰减至 0.85^(episode/1000)
- \( \gamma \)：折扣因子，设为 0.25
- \( R(s,a) \)：即时奖励
- \( \max_{a'} Q(s',a') \)：下一状态最大 Q 值

**用途**：更新成对模型（动作）在特定组装状态下的 Q 值。

## 11 结论正确解读

- **任务范围**：本文仅针对**有序**蛋白复合物（6-20 链），不涉及 IDP/IDR、膜蛋白、核酸复合物。
- **oracle/真值输入**：输入为链序列，无额外实验信息（如交联、SAXS）辅助；天然结构仅用于评测。
- **端到端状态**：AFM-RL 是**两阶段流水线**（pairwise 生成 + RL 组装），非端到端可微方法。
- **算力成本**：AFM pairwise 阶段需对每对链运行多次（冗余拷贝），计算成本高于单次 AFM；RL 阶段需数千 episode。
- **历史数据依赖**：AFM 预训练权重来自 PDB；RL 无需额外训练数据，但打分函数权重需在训练集上拟合。
- **模型依赖**：结果强依赖 AFM 的 pairwise 预测质量；若 AFM 对某链对预测失败，组装无法补救。
- **最难情形**：非对称、非球形、界面小且弱的复合物（如 1VF7 的 13 链双层结构）。
- **不确定性**：未报告置信度估计或模型可靠性指标；未与 CAPRI 标准评估对齐。
- **有边界的复述**：AFM-RL 在 6-20 链有序复合物上，通过强制采样 + RL 组装，平均 RMSD 10.09 Å，优于 MoLPC，但精度仍不足以直接用于原子级功能分析；对 IDP/IDR 体系无直接验证。

## 14 Agent 提炼的知识候选

> 面向「IDP/IDR × 蛋白互作 × AI/物理模拟」课题的可迁移知识：

1. **强制采样（forced sampling）策略**：对深度学习预测器输入冗余拷贝/扰动，可显著增加输出构象多样性。对 IDR 体系，可对同一 IDR 序列多次采样（如不同 MSA 深度、不同随机种子、不同截断），生成构象池，再筛选/组装。
2. **分解-组装框架**：将大复合物分解为 pairwise 子问题再组装，避免全局预测的算力瓶颈。对 IDR 介导的互作，可先预测 IDR 与伴侣的局部互作模块，再组装为完整复合物。
3. **RL 作为构象搜索策略**：Q-learning + UCB + ε-greedy 的组合可有效处理组合爆炸问题。对 IDR 构象采样，可将构象空间离散化为状态，用 RL 引导采样向低能区域集中。
4. **打分函数组合**：分子力学势 + 溶剂可及表面积 + 回旋半径 + 原子冲突数的线性组合，可迁移至 IDR 凝聚体打分，但需额外加入 IDR 特异性项（如电荷分布、疏水斑块）。
5. **冲突检查作为硬约束**：组装过程中实时检查原子冲突并拒绝无效路径，可迁移至 IDR 多价互作组装，避免生成物理上不可能的构象。
6. **聚类 + 排序输出**：对生成模型聚类后输出代表性模型，适合 IDR 构象池的降维与代表性选择。

## 15 与已有知识连接

- **AlphaFold-Multimer**（Evans et al., 2022, bioRxiv）：本文的 pairwise 生成器，AFM 本身可预测 2-3 链复合物，本文扩展至 6-20 链。
- **MoLPC**（Bryant et al., 2022, Nature Communications）：本文主要对比基线，MoLPC 采用分治策略预测大复合物，但存在界面缺失和冲突问题。
- **RL-MLZerD**（Aderinwale et al., 2022, Bioinformatics）：本文前作，首次将 RL 用于多链组装，本文用 AFM 替代 LZerD 作为 pairwise 生成器。
- **AlphaFold 3**（Abramson et al., 2024, Nature）：后续工作，可直接预测多链复合物，但内存限制仍存在；本文的分解-组装策略可作为补充。
- **IDP/IDR 相分离**：本文未涉及，但其「分解-组装」和「强制采样」思路与 IDR 构象系综采样（如 metadynamics、replica exchange）有方法论上的类比。
- **候选方向**：将 AFM-RL 的强制采样策略应用于 IDR 构象生成，或将 RL 组装框架用于多价 IDR 互作网络组装。

## 16 研究想法

> Agent 生成的研究候选

### 候选 1：IDR 构象系综的强制采样策略
- **来源局限/观察**：AFM-RL 通过冗余拷贝强制 AFM 输出多样化界面，显著提高覆盖率。
- **假设**：对 IDR 序列，通过向 AFM/AlphaFold 输入多拷贝或加扰动的 MSA，可生成比常规采样更多样的构象系综。
- **相对本文增量**：将强制采样从界面多样性扩展至构象多样性，适用于 IDR 单链/多链体系。
- **初步方法**：对同一 IDR 序列，构造不同 MSA 深度、不同截断、不同拷贝数的输入，收集 AFM 输出构象，用 RMSD 聚类评估多样性。
- **验证方式**：与常规 AFM 采样、分子动力学（MD）构象系综对比，评估构象空间覆盖度。
- **可能失败模式**：AFM 对 IDR 预测置信度低，输出构象可能不物理；需结合 MD 或实验验证。
- **创新状态**：unverified

### 候选 2：IDR 介导多价互作的 RL 组装框架
- **来源局限/观察**：AFM-RL 的 RL 框架可处理 6-20 链组装，IDR 介导的相分离涉及多价弱互作，组装逻辑类似。
- **假设**：将 IDR 互作位点（SLiMs、电荷斑块）视为组装单元，RL 可引导多价互作网络的逐步组装，生成凝聚体结构模型。
- **相对本文增量**：从有序复合物扩展至 IDR 介导的动态、多价互作网络。
- **初步方法**：将 IDR 互作位点离散化为状态，用 Q-learning 选择互作配对，奖励基于互作能/界面互补性。
- **验证方式**：与实验凝聚体结构（如 cryo-ET、SAXS）对比；与 MD 模拟的凝聚体性质对比。
- **可能失败模式**：IDR 互作高度动态，静态组装模型可能无法捕捉凝聚体动态性质。
- **创新状态**：unverified

### 候选 3：IDR 特异性打分函数扩展
- **来源局限/观察**：AFM-RL 的打分函数（分子力学 + SASA + RG + 冲突）不含 IDR 特异性项。
- **假设**：加入 IDR 特异性项（电荷-电荷相互作用、疏水斑块、芳香族堆积）可提高 IDR 复合物/凝聚体模型排序准确度。
- **相对本文增量**：将打分函数从有序复合物扩展至 IDR 体系。
- **初步方法**：在现有打分函数基础上，加入基于序列/结构的 IDR 特征项，用逻辑回归重新训练权重。
- **验证方式**：在 IDR 复合物/凝聚体数据集上评测排序准确度。
- **可能失败模式**：IDR 体系训练数据稀缺，权重可能过拟合。
- **创新状态**：unverified

### 候选 4：AFM-RL 与 MD 模拟的混合流水线
- **来源局限/观察**：AFM-RL 生成静态模型，未考虑构象动态。
- **假设**：将 AFM-RL 生成的模型作为 MD 模拟的初始构象，可加速 IDR 复合物/凝聚体的平衡采样。
- **相对本文增量**：从静态预测扩展至动态系综。
- **初步方法**：AFM-RL 生成模型 → 能量最小化 → MD 平衡 → 系综分析。
- **验证方式**：与纯 MD 从随机初始构象采样对比，评估采样效率。
- **可能失败模式**：AFM-RL 模型可能陷入局部能量极小，MD 无法逃逸。
- **创新状态**：unverified
