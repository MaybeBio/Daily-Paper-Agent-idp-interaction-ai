## 02 一句话总结

本文通过晶体结构、生化与细胞实验确定 SARS-CoV-2 N 蛋白 N 端 IDR1 中的 F17 残基插入 G3BP1 NTF2L 结构域疏水口袋，以竞争性方式阻断 G3BP1 与宿主应激颗粒蛋白（USP10、caprin 1）的互作，从而抑制应激颗粒组装；将 F17A 突变引入病毒基因组后，病毒在细胞和叙利亚金黄地鼠体内的复制与致病性均显著降低，证明 G3BP1-N 互作促进 SARS-CoV-2 感染。

## 03 研究问题

- **具体问题**：SARS-CoV-2 N 蛋白与宿主 G3BP1/2 之间的直接互作在病毒感染中发挥什么功能？这种互作是否通过抑制应激颗粒组装来促进病毒复制？
- **为什么重要**：G3BP1/2 是应激颗粒的核心组装因子，而应激颗粒被认为具有抗病毒功能。SARS-CoV-2 N 蛋白是感染细胞中最丰富的病毒蛋白，且在所有已知冠状病毒中保守地与 G3BP1/2 互作。理解这一互作的分子机制与功能后果，可能揭示病毒免疫逃逸的新机制，并为抗病毒干预提供靶点。
- **现有方法为何不足**：此前研究主要依赖过表达系统或体外实验，缺乏：(1) 原子分辨率的互作界面信息；(2) 选择性破坏该互作而不影响 G3BP1 其他功能的遗传工具；(3) 在活病毒和动物模型中的功能验证。G3BP1/2 敲除或敲低实验难以区分 N 蛋白互作的特异性效应与 G3BP1 缺失的全局性影响。
- **精确的 Can 问题**：Can a single point mutation (F17A) in the SARS-CoV-2 N protein that selectively abolishes G3BP1/2 binding attenuate viral replication and pathogenesis without disrupting other N protein functions?

## 04 背景与发展脉络

以下脉络基于本文引言与讨论，标注为「仅本文框架」——即作者在文中呈现的领域发展叙事，未经外部文献系统核验。

1. **阶段一：G3BP1/2 作为应激颗粒核心因子的发现**。G3BP1/2 是 paralogous RNA 结合蛋白，在应激条件下（包括病毒感染）促进应激颗粒形成。其 NTF2L 结构域是蛋白互作枢纽，多个宿主蛋白（USP10、caprin 1）和病毒蛋白通过该结构域结合，且这些结合是相互排斥的。
2. **阶段二：SARS-CoV-2 N 蛋白与 G3BP1/2 互作的鉴定**。多个蛋白质组学研究（包括作者自己的）一致发现 N 蛋白是 G3BP1/2 的最显著互作蛋白。N 蛋白含三个 IDR（N-arm/IDR1、linker/IDR2、C-tail/IDR3），其中 IDR1 前 25 个氨基酸被鉴定为 G3BP1 结合所必需。
3. **阶段三：结构解析与机制假设**。已有晶体结构显示 N 蛋白 N 端肽段插入 G3BP1 NTF2L 疏水口袋，但缺乏与其他 NTF2L 互作蛋白的系统比较，也缺乏功能验证。
4. **阶段四（本文位置）**：作者将结构信息转化为功能性遗传工具——通过 F17A 突变选择性破坏 N-G3BP1 互作，在保持 N 蛋白其他功能（RNA 结合、相分离、病毒组装）不变的前提下，在活病毒和动物模型中验证该互作的功能意义。本文主张：N 蛋白通过竞争性占据 NTF2L 口袋来"重连"G3BP1 互作网络，抑制应激颗粒组装，从而保护病毒 RNA 不被隔离。

## 06 核心思想

### 1) 表面方法

- 结构生物学：解析 G3BP1 NTF2L 与 N 蛋白 N 端肽段（WT、D3L、P13L 突变体）的共晶结构
- 生化分析：体外 pulldown、SPR 测定结合亲和力
- 细胞生物学：共定位、应激颗粒组装/拆解实验、G3BP1 互作组比较（WT vs F17A N 蛋白）
- 病毒学：反向遗传学构建 N-F17A 重组 SARS-CoV-2，在 Vero E6、Calu-3 细胞中测定复制动力学，在叙利亚金黄地鼠中测定致病性
- 相分离实验：体外液-液相分离（LLPS）实验，测试 N 蛋白与 G3BP1 的共凝聚

### 2) 核心洞察

- **结构洞察**：所有已知 NTF2L 互作蛋白（宿主 USP10、caprin 1、Nup-FxFG 和病毒 N、nsP3）都通过插入一个苯丙氨酸侧链到同一疏水口袋来结合 G3BP1/2。N 蛋白的 F17 是这一"通用钥匙"的关键残基。
- **功能洞察**：N 蛋白通过占据 NTF2L 口袋，竞争性取代 USP10 和 caprin 1，从而"重连"G3BP1 互作网络，使其无法组装应激颗粒。这解释了为什么 N 蛋白高表达时应激颗粒被抑制。
- **进化洞察**：F17 在所有 SARS-CoV-2 变异株中 100% 保守（n=8,297,154 基因组），而邻近的 P13L 突变（Omicron）轻微降低结合亲和力，提示该互作对病毒适应性的重要性。
- **机制模型**：N 蛋白表达水平是开关——低水平时不足以竞争 G3BP1 互作网络，应激颗粒形成并隔离病毒 RNA；高水平时 N 蛋白占据 NTF2L 口袋，拆解应激颗粒，释放病毒 RNA 用于翻译和复制。

### 3) 可能的普适教训 [Analysis]

- **IDR 介导互作的可成药性**：本文证明一个位于 IDR 内的单个芳香族残基（F17）可以驱动高亲和力、高特异性的蛋白互作，且该互作可通过点突变精确拆解。这提示 IDR 并非"不可成药"的模糊区域，而是包含可定位的热点残基。
- **结构-guided 突变作为因果推断工具**：在相分离/凝聚体研究中，仅做敲除或过表达难以建立因果关系。本文展示了如何利用结构信息设计"只破坏一对互作、不影响其他功能"的突变，这是建立因果链的黄金标准。
- **竞争性结合作为凝聚体调控机制**：凝聚体的组装/拆解可由一个"占位者"蛋白通过竞争关键 hub 蛋白（如 G3BP1）的结合位点来调控。这种机制可能广泛存在于 IDP 介导的互作网络中。

## 07 方法总览

- **输入**：
  - 蛋白序列：SARS-CoV-2 N 蛋白（WT 及突变体）、G3BP1 全长及结构域构建体
  - 肽段：N 蛋白 N 端 1-25 aa（WT、D3L、P13L）、USP10 1-25、caprin 1 361-381、nsP3 449-473
  - 病毒：SARS-CoV-2 WA-1 株及 N-F17A 重组病毒
  - 基因组数据：GISAID 8,297,154 条 SARS-CoV-2 序列
- **输出**：
  - 共晶结构（G3BP1 NTF2L + 各肽段）
  - 结合亲和力（SPR K_D 值）
  - 互作组差异（WT vs F17A N 蛋白的质谱比较）
  - 病毒复制动力学曲线、动物体重变化曲线、组织病理评分
  - 应激颗粒定量数据（免疫荧光）
- **模块**：
  1. 结构解析模块（晶体筛选、衍射数据收集、分子置换、结构精修）
  2. 生化互作模块（pulldown、SPR）
  3. 细胞互作组模块（GFP-Trap 质谱）
  4. 相分离模块（体外 LLPS 实验）
  5. 病毒学模块（反向遗传学、复制动力学、动物实验）
  6. 生物信息学模块（GISAID 序列变异分析）
- **训练**：不适用（无机器学习模型）
- **工具**：X 射线晶体学（ESRF 同步辐射）、Biacore T200 SPR、质谱（LC-MS/MS）、共聚焦显微镜、BSL3 病毒操作
- **反馈回路**：结构信息 → 设计突变 → 体外验证 → 病毒验证 → 动物验证；序列变异分析 → 评估保守性 → 支持功能重要性
- **假设**：
  - N 蛋白 F17 是 G3BP1 结合的关键残基（由结构指导）
  - F17A 突变不影响 N 蛋白的其他功能（RNA 结合、二聚化、相分离）
  - 叙利亚金黄地鼠是 SARS-CoV-2 致病性的合适模型
  - G3BP1 和 G3BP2 功能冗余，因此只检测 G3BP1 互作即可代表

**文字流程**：作者首先通过质谱确认 N 蛋白与 G3BP1/2 的互作 → 通过截短实验定位互作区域（N 蛋白 N 端 1-25 aa；G3BP1 NTF2L 结构域）→ 解析共晶结构确定原子级互作界面 → 基于结构设计 F17A 突变 → 体外验证 F17A 破坏互作但不影响 N 蛋白其他功能 → 将 F17A 引入病毒基因组 → 在细胞中测定复制表型 → 在地鼠中测定致病性 → 结合 GISAID 序列分析证明 F17 保守性 → 提出机制模型。

## 09 关键公式符号

本文为实验生物学论文，不涉及数学模型或算法公式。以下列出与理解实验设计相关的定量关系：

1. **SPR 结合亲和力**：K_D = k_off / k_on，其中 K_D 为平衡解离常数，k_off 为解离速率常数，k_on 为结合速率常数。本文中 N 1-25 -WT 与 NTF2L 的 K_D = 1.14 μM，N 1-25 -P13L 的 K_D = 2.6 μM，N 1-25 -D3L 的 K_D = 1.10 μM（Results 图 2E）。

2. **病毒滴度比较**：文中使用 focus forming assay (FFA) 定量感染性病毒颗粒，以 focus forming units per mL (FFU/mL) 表示。F17A 病毒在 Calu-3 细胞 24 hpi 时滴度较 WT 降低 >8 倍（Results 图 4E）。

3. **统计检验**：文中使用 one-way ANOVA 和 two-tailed Student's t test（Methods 统计部分），显著性阈值未在摘要中明确给出。

## 10 实验设计与证据链

**数据集/群体**：
- 细胞系：HEK293T（互作组、共定位）、Vero E6 和 Vero E6-TMPRESS2（病毒复制）、Calu-3 2b4（人呼吸道细胞系，病毒复制）、U2OS-tdTomato-KI G3BP1（应激颗粒成像）
- 动物：3-4 周龄雄性叙利亚金黄地鼠（n=5/组/时间点，基于"cohorts of 5 animals"）
- 病毒：SARS-CoV-2 WA-1 株（WT）及重组 N-F17A 突变株
- 序列数据：GISAID 8,297,154 条 SARS-CoV-2 基因组（2022年3月访问）

**指标**：
- 蛋白互作：pulldown 共沉淀、SPR K_D
- 应激颗粒：免疫荧光共定位、颗粒数量/面积
- 病毒复制：FFU/mL 滴度、GFP 阳性细胞百分比
- 致病性：体重变化、肺组织病理评分
- 互作组：质谱谱图计数

**基线/对照**：
- F17A/F17W 突变体作为"互作破坏"对照
- G3BP1/2 DKO 细胞作为"无 G3BP"背景

## 11 结论正确解读

- **任务范围**：本文只研究了 SARS-CoV-2 N 蛋白与 G3BP1/2 的互作，不涉及其他病毒蛋白或宿主蛋白。结论仅适用于 N 蛋白 N 端 IDR1 中 F17 介导的互作。
- **oracle/真值输入**：结构-guided 突变（F17A）是核心干预手段，其"特异性"依赖于 F17A 不改变 N 蛋白其他功能（RNA 结合、相分离、二聚化）的验证。这些验证实验的结果在摘要中未完整呈现，需查阅全文确认。
- **端到端状态**：从分子互作 → 细胞表型 → 病毒复制 → 动物致病性的完整链条已建立，但"应激颗粒抑制"与"病毒复制促进"之间的因果关系是推断性的——作者没有直接证明应激颗粒的拆解是病毒复制增强的原因（例如，没有在应激颗粒缺陷细胞中测试 F17A 病毒是否仍有复制缺陷）。
- **算力成本**：不适用（无计算模型）。
- **历史数据依赖**：GISAID 序列分析仅覆盖截至 2022 年 3 月的数据，不包含后续出现的变异株（如 BA.2.86、JN.1 等）中 N 蛋白的突变情况。
- **模型依赖**：不适用。
- **最难情形**：作者承认体外细胞系结果不一致（Vero E6 中 F17A 反而略有增强），说明 N-G3BP1 互作的功能效应具有细胞类型依赖性。在体内，F17A 的减毒效应在呼吸道（肺）中显著，但其他组织（如嗅上皮）未检测。
- **群体/领域边界**：结论基于叙利亚金黄地鼠模型，该模型虽广泛用于 SARS-CoV-2 研究，但不能完全代表人类感染。F17A 的减毒效应是否在人类中同样显著，无法从本文推断。
- **不确定性**：作者没有提供 F17A 病毒在免疫缺陷动物或老年动物中的数据；没有提供 F17A 对疫苗效力或传播能力的影响；没有提供 N-G3BP1 互作在 SARS-CoV-2 进化中的选择压力分析。

**有边界的复述**：在叙利亚金黄地鼠模型中，SARS-CoV-2 N 蛋白通过其 N 端 IDR1 中的 F17 残基与宿主 G3BP1/2 的 NTF2L 结构域互作，该互作对病毒在肺组织中的复制和致病性有显著贡献；F17A 突变特异性破坏该互作，导致病毒减毒，但 N 蛋白的其他功能（RNA 结合、相分离）不受影响。

## 14 Agent 提炼的知识候选

以下为面向「无序蛋白/无序区(IDP/IDR)介导的蛋白互作（含相分离/凝聚体）× AI/深度学习 或 物理模拟」课题方向的可迁移知识：

1. **单残基热点驱动 IDR 互作的概念**：本文证明 IDR 内的单个芳香族残基（F17）可以驱动与折叠结构域（NTF2L）的高亲和力互作。对 IDP/IDR 研究的意义：在无序区域中寻找"锚定残基"（anchor residues）可能比整体序列分析更有效。**可迁移方法**：在 AI 预测 IDR 互作位点时，可优先关注芳香族残基（F/W/Y）在疏水口袋中的插入模式，类似 AlphaFold-Multimer 或 peptide docking 中的热点预测。

2. **竞争性占位作为凝聚体调控机制**：N 蛋白通过占据 NTF2L 口袋，竞争性取代 USP10/caprin 1，从而"重连"G3BP1 互作网络。**可迁移概念**：在相分离体系中，一个"外来"IDR 可以通过竞争 hub 蛋白的关键结合位点来拆解或重塑凝聚体，而不需要直接与凝聚体组分发生相分离。**可迁移方法**：在建模 IDP 介导的凝聚体时，可引入"竞争性结合"参数——即外来蛋白对 hub 蛋白结合位点的占据率如何影响网络连通性和相分离阈值。

3. **结构-guided 突变作为因果推断工具**：本文利用晶体结构信息设计 F17A 突变，实现"只破坏一对互作、不影响其他功能"的精确干预。**可迁移方法**：在 IDP/IDR 功能研究中，如果已有复合物结构或 AlphaFold 预测模型，应优先使用结构-guided 突变而非大片段截断或敲除，以避免多效性效应。对 AI 方法而言，这提示预测"功能丧失突变"时需要考虑互作特异性而非仅预测结合亲和力变化。

4. **IDR 互作的"通用钥匙"模式**：多个结构无关的蛋白（宿主 USP10、caprin 1、Nup-FxFG 和病毒 N、nsP3）都通过插入苯丙氨酸到同一口袋来结合 G3BF1 NTF2L。**可迁移概念**：IDR 互作可能收敛到少数几种"结合模式"（binding modes），而非无限多样。**可迁移方法**：在开发 IDR 互作预测工具时，可建立"口袋-芳香族残基插入"的模板库，类似 kinase 抑制剂中的 pharmacophore 模型。

5. **表达水平作为功能开关**：N 蛋白表达水平从低到高转变时，对应从"允许应激颗粒形成"到"抑制应激颗粒形成"的功能切换。**可迁移概念**：IDR 介导的互作网络可能具有浓度依赖的开关行为，这在相分离体系中尤为重要（临界浓度概念）。**可迁移方法**：在建模 IDP 介导的凝聚体时，应显式考虑蛋白浓度的动态变化，而非仅关注稳态。

6. **体内外结果不一致的警示**：Vero E6 与 Calu-3 细胞中 F17A 效应相反，说明 IDR 互作的功能后果具有细胞类型依赖性。**可迁移教训**：在 IDP/IDR 功能预测中，单一细胞系的结果可能具有误导性；AI 模型训练时需注意细胞类型/组织特异性。

7. **序列保守性分析支持功能重要性**：F17 在 800 万条 SARS-CoV-2 基因组中 100% 保守，而邻近残基有变异。**可迁移方法**：在大规模序列数据中评估 IDR 内特定残基的保守性，可作为功能重要性的第一层证据，尤其对于无序区域（通常保守性低，但关键功能残基可能高度保守）。

## 15 与已有连接

- **相似连接**：本文与 Kruse et al. (2021, PNAS) 关于 SARS-CoV-2 N 蛋白与 G3BP1 互作的结构研究一致，均鉴定 F17 为关键残基。本文的增量在于功能验证（病毒突变体 + 动物模型）。与 Yang et al. (2021, JBC) 关于 N 蛋白相分离的研究互补：后者关注 N 蛋白自身的相分离行为，本文关注 N 蛋白与宿主 G3BP1 的互作如何调控宿主凝聚体。
- **组合连接**：本文的"竞争性占位"机制可与相分离领域的"scaffold-client"模型（Banani et al., 2017, Nat Rev Mol Cell Biol）结合：G3BP1 是应激颗粒的 scaffold，N 蛋白作为"client"通过竞争 scaffold 的结合位点来拆解凝聚体。这一框架可推广到其他病毒-宿主互作。
- **冲突连接**：部分文献报道 G3BP1 敲低促进 SARS-CoV-2 复制（如 Nabeel-Shah et al., 2022, iScience），而本文显示 N-G3BP1 互作促进复制。可能的解释：G3BP1 具有双重功能（应激颗粒形成 vs. 其他 RNA 代谢功能），敲除与互作破坏的效应不同。这一冲突提示 IDP 互作研究中"互作特异性扰动"优于"蛋白水平扰动"。
- **可迁移领域**：本文的结构-guided 突变策略可迁移到其他 IDR 介导的病毒-宿主互作研究（如流感病毒 NS1、Zika 病毒 capsid 与 G3BP1 的互作）。在 AI 方法层面，本文的"单残基热点"概念可迁移到蛋白-蛋白互作预测器的可解释性分析中，用于识别预测结构中的关键残基。

## 16 Agent 生成的研究候选

以下为面向「IDP/IDR 介导的蛋白互作 × AI/深度学习 或 物理模拟」课题方向的研究想法：

### 候选 1：基于结构-guided 突变的 IDR 互作热点预测器
- **名称**：IDR-Anchor：无序区锚定残基预测工具
- **来源局限/观察**：本文证明 IDR 内单个芳香族残基（F17）可驱动高亲和力互作，但现有 IDR 互作预测工具（如 IUPred、Anchor）主要基于序列特征，未充分利用复合物结构信息
- **核心假设**：IDR 内的功能关键残基可通过"是否插入折叠结构域疏水口袋"来识别，且该特征可从 AlphaFold 预测的复合物结构中提取
- **相对本文的增量**：将本文的单案例发现推广为可泛化的预测工具
- **初步方法**：收集已知 IDR-折叠结构域复合物结构（PDB），标注插入疏水口袋的芳香族残基；训练一个图神经网络，输入为 AlphaFold-Multimer 预测的复合物结构，输出为 IDR 内每个残基的"锚定概率"；在病毒-宿主互作组（如 SARS-CoV-2 N、nsP3 等）上验证
- **验证方式**：与已知突变数据（如本文 F17A）比较；在未参与训练的病毒蛋白上测试预测准确率
- **可能的失败模式**：AlphaFold 对 IDR 的预测置信度低，可能导致结构特征不可靠；疏水口袋插入可能不是唯一的 IDR 互作模式
- **创新状态**：unverified

### 候选 2：竞争性占位驱动的凝聚体拆解动力学模型
- **名称**：Competitive Displacement Model for Stress Granule Disassembly
- **来源局限/观察**：本文提出 N 蛋白通过竞争 NTF2L 口袋拆解应激颗粒，但缺乏定量模型描述这一过程的时间尺度和浓度依赖性
- **核心假设**：凝聚体的拆解速率由外来蛋白对 scaffold 结合位点的占据率决定，且存在临界占据率阈值
- **相对本文的增量**：将定性机制转化为可预测的定量模型
- **初步方法**：基于本文的 SPR 数据（K_D 值）和细胞内 N 蛋白浓度范围，构建一个质量作用动力学模型；将 G3BP1 网络简化为 scaffold-client 竞争系统，用常微分方程模拟应激颗粒组装/拆解的时间过程；用本文的细胞实验数据（应激颗粒定量）拟合模型参数
- **验证方式**：预测不同 N 蛋白表达水平下应激颗粒的稳态大小和拆解速率，与本文图 6 的定量数据比较；在 G3BP1/2 DKO 回补实验中验证
- **可能的失败模式**：细胞内凝聚体行为受多因素调控（RNA 浓度、翻译状态），简化模型可能无法捕捉关键动态
- **创新状态**：unverified

### 候选 3：IDR 互作热点的大规模序列-结构共变分析
- **名称**：Coevolutionary Signatures of IDR-Mediated Interactions
- **来源局限/观察**：本文通过 GISAID 分析证明 F17 在 800 万条序列中 100% 保守，但未系统分析 IDR 内其他残基的共变模式
- **核心假设**：IDR 内与折叠结构域互作的关键残基可通过跨物种/跨变异株的共变分析来识别，且共变信号可辅助 AlphaFold 预测 IDR 互作界面
- **相对本文的增量**：将本文的单一保守性分析扩展为系统的共变分析框架
- **初步方法**：收集 SARS-CoV-2 及相关冠状病毒的 N 蛋白序列，计算 IDR1 内残基对之间的互信息；将高共变残基对映射到本文的晶体结构上，验证是否位于互作界面；开发一个结合共变信号和 AlphaFold 预测的集成打分函数
- **验证方式**：在已知互作界面（本文结构）上评估共变信号的富集程度；在未解析结构的冠状病毒 N 蛋白上预测互作界面，并用交联质谱验证
- **可能的失败模式**：IDR 序列保守性低，共变信号可能被系统发育噪声淹没；单链 RNA 病毒的高突变率可能破坏共变信号
- **创新状态**：unverified

### 候选 4：IDR 介导互作的分子动力学模拟力场参数化
- **名称**：Force Field Benchmarking for IDR-Mediated Interactions
- **来源局限/观察**：本文的晶体结构显示 F17 插入疏水口袋，但静态结构无法揭示结合/解离的动力学路径和熵贡献
- **核心假设**：现有分子动力学力场（如 CHARMM36m、AMBER ff19SB）能否准确描述 IDR 肽段与折叠结构域的结合自由能，取决于对 IDR 构象系综的采样充分性
- **相对本文的增量**：为 IDR 互作的 MD 模拟提供基准测试和力场选择指南
- **初步方法**：以本文的 NTF2L-N 1-25 复合物为模型体系，分别用 CHARMM36m、AMBER ff19SB、OpenFF 等力场进行增强采样 MD（如 replica exchange、metadynamics）；计算结合自由能（MM-PBSA、FEP），与 SPR 实验值（K_D = 1.14 μM）比较；分析 IDR 肽段在结合前后的构象熵变化
- **验证方式**：预测的 K_D 值与实验值的误差；模拟中观察到的关键接触是否与晶体结构一致
- **可能的失败模式**：IDR 的构象空间巨大，即使增强采样也可能无法充分收敛；力场对芳香族-芳香族相互作用的描述可能不准确
- **创新状态**：unverified

### 候选 5：基于深度学习的 IDR 互作竞争性结合位点预测
- **名称**：DeepIDR-Competitor：预测 IDR 蛋白对 hub 蛋白结合位点的竞争能力
- **来源局限/观察**：本文证明 N 蛋白与宿主蛋白竞争同一 NTF2L 口袋，但缺乏工具预测哪些病毒/宿主 IDR 蛋白具有类似的竞争能力
- **核心假设**：IDR 蛋白对特定折叠结构域口袋的竞争能力可从序列和预测结构中学习，且该能力与 IDR 内的芳香族残基密度和周围序列特征相关
- **相对本文的增量**：将本文的竞争性结合概念推广为可泛化的预测工具
- **初步方法**：收集已知 NTF2L 结合蛋白（USP10、caprin 1、Nup、ns3P、N 蛋白等）及非结合蛋白作为训练集；提取序列特征（芳香族残基密度、IDR 预测分数）和结构特征（AlphaFold 预测的局部结构）；训练一个分类器预测"是否竞争性结合 NTF2L 口袋"；扩展到其他已知的 hub 蛋白（如 SMN、DCP1A）
- **验证方式**：在留出测试集上的 AUC；用本文的 F17A 突变体作为阴性对照验证预测
- **可能的失败模式**：训练集规模小（已知 NTF2L 结合蛋白有限）；IDR 互作的序列特征可能过于分散，难以学习
- **创新状态**：unverified
